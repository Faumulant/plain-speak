# plain-speak —— 工程输出守则

一个约束 agent 自然语言输出的技能（Agent Skills 格式）：让 agent 在工程作业时
结论先行、按输出类型套必填信息集、简洁不丢信息、不自创词语、不输出空洞术语。

## 安装

把 SKILL.md 放到 agent 的技能目录：

```
~/.agents/skills/plain-speak/SKILL.md
```

Windows 下即 `C:\Users\<你的用户名>\.agents\skills\plain-speak\SKILL.md`。
支持 Agent Skills 规范的工具（Claude Code、ZCode 等）会自动发现它；
也可以随时手动调用 `/plain-speak`。

## 接线（条件指针）

技能只在被加载时生效。在 agent 的全局指令文件里加一段条件指针，
让工程任务时自动加载：

```markdown
## 做工程任务时（写/改代码、排查问题、方案设计、技术文档）

- 先读 <技能目录>/plain-speak/SKILL.md，按它输出。
- 工作纪律：
  - 拆分以决策点和风险点为界，能合并的小任务合并成一批干；不做最小颗粒度拆解。
  - 完成即停：达到要求就收工，不做第二轮抛光，不重复优化已收敛的部分。
  - 不为想象中的未来需求加抽象、加配置、加防御。
  - 同一处两轮没收敛就换思路或汇报，不原地打转。
```

各工具的全局指令文件位置：

- ZCode：`~/.zcode/AGENTS.md`
- Codex：`~/.codex/AGENTS.md`
- Claude Code：`~/.claude/CLAUDE.md`

## 设计要点

- 三层结构：信息层（按输出类型套必填骨架）→ 密度层（每句话存留测试）→ 语言层（禁自创词、空洞术语、AI 腔）。
- 纠偏原则：基线是需求，不是上一版输出——收到纠正后重新生成，禁止「修正版」式打补丁。
- 确认跟着决策点走，不跟着任务碎片走：能合并的小任务合并成一批做。
- 只在工程作业时生效，日常对话不加载。
